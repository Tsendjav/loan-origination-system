# 🎯 LOS — Банк / ББСБ-д зориулсан иж бүрэн систем болгох замын зураг

Энэ баримт нь одоогийн систем **юу хийдэг**, банк, банк бус санхүүгийн байгууллага (ББСБ),
зээлийн үйлчилгээ үзүүлэгчийн шаардлагад нийцүүлэхэд **юу дутагдаж байгаа**, түүнийг
ямар дарааллаар шийдэхийг харуулна.

> Тэмдэглэл: доорх интеграцууд (Монголбанкны Зээлийн мэдээллийн сан, ХУР, ДАН) нь
> байгууллага хоорондын гэрээ, API credential, мэдээлэл солилцох зөвшөөрөл шаарддаг.
> Тиймээс кодын талд **adapter интерфэйс + mock provider** хийж, бодит endpoint-ыг
> credential авсны дараа солих нь зөв арга.

| 4 | **Зөвшөөрөл (consent) ба аудит** | Харилцагчаас мэдээлэл татах зөвшөөрөл авах, хэн, хэзээ, юу татсаныг өөрчлөх боломжгүй audit log-д бүртгэх. |

| 6 | **Баримт бичгийн удирдлага** | Иргэний үнэмлэх, орлогын тодорхойлолт, гэрээ upload; OCR/verify; хугацаа, хэмжээ, төрлийн хязгаар; S3/MinIO. |
| 7 | **Зээлийн гэрээ ба e-гарын үсэг** | Гэрээний загвар (PDF), гарын үсэг (Dan/eSign), хадгалалт, хувилбар. |
| 8 | **Тайлан, экспорт** | Монголбанк/СЗХ-ны тайлан, зээлийн багц, NPL, хоцрогдлын тайлан; Excel/CSV/PDF экспорт. |
| 9 | **Мэдэгдэл** | SMS/email (загвар, retry, түүх), шийдвэрийн мэдэгдэл. Одоо зөвхөн stub (`emailEnabled=false`). |
| 10 | **Нууц үг/2FA бодлого** | Нууц үг солих, түгжих бодлого, 2FA (TOTP/SMS), session timeout, refresh token. Одоо demo хэрэглэгчид hardcode. |

## 5. Интеграцын архитектур (санал)

```
LoanApplicationService
        │
        ▼
CreditDecisionService ──► ScoringEngine (дүрэм + оноо)
        │                        │
        │                        ├── CreditBureauPort   → Монголбанк ЗМС (эсвэл mock)
        │                        ├── CitizenRegistryPort→ ХУР
        │                        └── TaxDataPort        → ДАН
        ▼
DecisionResult (APPROVED / UNDER_REVIEW / REJECTED + шалтгаан)
```

- Порт бүр нь `interface` + `MockXxxAdapter` (`@Profile("!prod")`) + `RealXxxAdapter` (`@Profile("prod")`).
- Хариу бүрийг `IntegrationCallLog` (хүсэлт ID, хугацаа, статус, hash) болгон хадгална — аудит.
- Гадаад систем унасан үед `UNDER_REVIEW` руу шилжиж, гараар шийдэх fallback.
- Timeout/retry/circuit breaker (Resilience4j), PII-г логт бичихгүй.

## 6. Дараагийн 30 / 60 / 90 хоног

**30 хоног**
1. Scoring engine (DTI, орлого, түүх) + дүрэм тохируулах UI.
2. `CreditBureauPort` + mock, `IntegrationCallLog`, шийдвэрийн тайлбар (reason codes).
3. Баримт upload (MinIO) + KYC урсгал.
4. Audit log (шийдэл, өөрчлөлт).

**60 хоног**
5. ХУР/ДАН adapter (credential авсан тохиолдолд), consent.
6. Тайлан/экспорт, мэдэгдэл (SMS/email).
7. 2FA, нууц үгийн бодлого, session.
8. E2E тест, load test, staging deploy.

**90 хоног**
9. Гэрээ + e-гарын үсэг, олголт/төлбөрийн интеграц.
10. Коллекшн, нягтлан, AML screen.
11. Multi-tenant, BI dashboard.
12. Аюулгүй байдлын аудит, backup/DR, production hardening.
